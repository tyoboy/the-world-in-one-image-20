One picture of Friday 20 November 2026: a front page that names the day and sums up its world news in eight stories — the UN court's genocide ruling on Myanmar as the lead, Trump putting the Iran decision off to 2027, GTA VI passing $1.80bn in sales, Cyclone Akvan's landfall in Odisha, Voyager 1 reaching a full light-day out, Hayabusa2's cancelled asteroid landing, Europe ready for talks with Russia, and the Houthi strike on Riyadh. The image ships as `entry.png`; `main.ts` checks it against the gate's rules (whole PNG/JPEG, ≤ 1 MiB, ≤ 1024×1024) and copies it byte for byte to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
